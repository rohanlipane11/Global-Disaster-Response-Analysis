# 🌍 Global Disaster Response Analysis

## 📊 Power BI Data Analytics Project

Global Disaster Response Analysis is a Power BI-based data analytics project developed to analyze disaster events, affected populations, casualties, damages, geographical patterns, and response-related information from 2018 to 2024.

---

## 🎯 Project Objective

The main objective of this project is to analyze global disaster data and identify important patterns and trends using Power BI.

The project focuses on:

- Disaster frequency analysis
- Geographical distribution of disasters
- Casualties and affected population
- Economic damage analysis
- Year-wise disaster trends
- Disaster type analysis
- Interactive filtering and visualization

---

## 🛠️ Technologies Used

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Cleaning
- Data Visualization
- Data Analysis

---

## 📂 Dataset

The dataset contains global disaster-related information covering the period from 2018 to 2024.

Main analysis areas include:

- Disaster Type
- Country
- Region
- Date
- Casualties
- Affected Population
- Economic Damage
- Response-related information
